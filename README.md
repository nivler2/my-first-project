# NEON SWARM: CHROMA DEFENSE

A browser-based arcade prototype where you defend a central core from color-coded alien swarms.

## Controls
- Move: `WASD` or Arrow keys
- Aim: Mouse
- Fire: Hold mouse button
- Switch color: `1` (Red), `2` (Blue), `3` (Green)
- Dash: `Space`
- Color pulse: `Shift`
- Restart after game over: `R`

## Objective
Survive the 3-minute timer while keeping both your ship and the central core alive. Matching shot color to enemy color deals much higher damage and enables stronger combo scoring.
